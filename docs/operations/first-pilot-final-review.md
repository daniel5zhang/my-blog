# Daniel实验室 - 第一次真实试运行终审与收口清单

## 1. 内容终审
- 首发内容是否已通过内部演练
- 网站母稿、平台草稿、专题归属是否一致
- 标题是否已经做最终人工确认
- 结尾 CTA 是否自然回流到网站母稿
- 是否还有明显可读性问题、语气问题、信息重复问题

## 2. 平台终审
- 首发平台是否已收敛到 1-2 个，不做全平台齐发
- 每个平台版本是否符合该平台表达习惯
- 微博/小红书等短内容平台，是否已经压缩到足够短促
- 是否已经明确每个平台的发布时间窗口

## 3. 发布边界终审
- 本次是否只做“小规模试运行”，没有扩成正式全面发布
- 是否仍需人工点击/人工确认，避免误触真实自动发布
- 是否确认不修改生产环境变量、不触碰外部自动化配置

## 4. 回写准备
- 是否明确发布后要记录哪些反馈
- 是否提前确定由谁回写台账
- 是否提前约定成功 / 失败判断口径

## 5. 最终放行结论
终审后只能给三种结论：
- 放行试运行
- 退回微调后再审
- 暂缓本轮试运行
