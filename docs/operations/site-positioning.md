# Daniel实验室 - 站点定位说明

## 当前定位
Daniel实验室 是一个**文章型内容中枢**。

它的角色不是作品集，不是项目展示站，也不是多平台分发控制台。
它的职责很明确：
- 先在网站完成母稿创作与沉淀
- 再在后续阶段把内容改写并分发到外部平台

## 当前信息架构
一级结构收敛为：
- 首页
- 文章
- 专题
- 标签
- 归档
- 关于
- 订阅
- 搜索

## 关于 projects
- `projects` 底层数据当前仍保留，仅作历史兼容
- 前台不再把它作为独立内容类型暴露
- 后续如果要处理，会单独决定是迁移为专题案例，还是彻底下线路由

## 专题的角色
- 专题是第二主轴，不是新的复杂 CMS
- 它的作用是把零散文章按长期问题域重新组织起来
- 当前阶段保持最小可用：专题聚合页 + 相关文章入口

## 外部分发原则
- 网站是母稿源头
- 外部分发平台后续从网站母稿改写
- 当前阶段不做多平台自动发布
