## 正文模板
```md
# 标题

> 用一句话先把核心判断说出来。

## 这件事为什么值得写

回答三个问题：
- 发生了什么
- 为什么不只是一个短期热点
- 对 Daniel实验室 的长期问题域有什么价值

## 我的核心判断

直接给出判断，不要绕。

## 这背后的变化是什么

拆成 2-4 个关键点。

### 1. 关键变化一

### 2. 关键变化二

### 3. 关键变化三

## 对读者最实际的影响

写“这会改变什么”，而不是只复述新闻。

## Daniel实验室 的结论

用更有态度的方式收尾，给出后续值得继续观察的方向。
```

## 写作提醒
- 先讲判断，再讲信息
- 不要写成资讯搬运
- 不要空喊“趋势来了”
- 文章必须能挂进某个专题
