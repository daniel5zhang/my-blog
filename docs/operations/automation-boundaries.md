# Daniel实验室 - 半自动运营边界与节奏

## 一、哪些动作允许自动执行
允许自动执行的动作：
- 站内文章草稿生成
- 标题、摘要、标签、专题建议生成
- 首页推荐候选清单生成
- Feed、搜索、归档、专题聚合更新
- 外部分发草稿改写（仅草稿）
- 周发布计划草案生成
- 评论/反馈整理

这些动作的共同特点：
- 不直接对外发布
- 可回看、可修改、可撤销
- 不涉及真实账号对外动作

## 二、哪些动作必须人工确认
必须人工确认的动作：
- 发布到公众号 / 小红书 / 微博 / 抖音 / 技术社区
- 修改生产环境变量
- 删除历史内容
- 调整站点正式域名、评论仓库、统计配置
- 覆盖主分支的高风险 Git 操作
- 任何不可逆操作

## 三、推荐内容生产节奏
### 日节奏
- 每日：收集素材、形成候选选题
- 每日：若有合适主题，产出 1 篇网站母稿或草稿

### 周节奏
- 每周 1 次：整理专题更新
- 每周 1 次：刷新首页推荐候选
- 每周 1 次：决定哪些母稿值得进入外部分发改写

### 月节奏
- 每月 1 次：复盘哪些专题值得继续投入
- 每月 1 次：梳理哪些文章可升级为 Daniel实验室 的长期代表作

## 四、推荐发布节奏
建议先采用低频稳定节奏：
- 网站：每周 2-4 篇
- 公众号：每周 1-2 篇（从网站母稿改写）
- 小红书：每周 2-3 条（从网站观点切片）
- 微博：按观点切片灵活发，但必须经过人工确认
- 抖音：只做脚本储备，不在本阶段自动发布

## 五、执行顺序
1. 网站母稿
2. 专题归类
3. 首页/订阅更新
4. 各平台改写草稿
5. 人工审核
6. 外部发布
