# Daniel实验室 - 选题池模板

> 适用角色：`canmou` / `main` / `creator`

## 使用方式
- `canmou` 先把候选选题补进来
- `main` 做优先级判断与范围冻结
- `creator` 领取已冻结选题进入写作

## 选题池表格
| 选题标题 | 问题域/专题 | 选题价值 | 目标读者 | 角度判断 | 素材来源 | 优先级 | 当前状态 | 负责人 | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| 示例：AI Agent 会不会重写白领工作流 | 自动化实践 | 能承接长期专题，也适合平台切片 | 已经在用 AI 工具的内容/运营/产品人 | 不讲大词，讲真实工作位被改写的地方 | 行业新闻 + 自身实践 | 高 | 待冻结 | canmou | 可衍生公众号/小红书/微博版本 |

## 字段说明
- **选题标题**：先写工作标题，不要求一步到位
- **问题域/专题**：优先挂到 `AI观察 / 自动化实践 / 数字工作流`
- **选题价值**：为什么值得写，不要只写“热点”
- **目标读者**：这篇文章主要写给谁
- **角度判断**：Daniel实验室 的核心观点或切入口
- **素材来源**：新闻、产品更新、自己的实践、社区反馈
- **优先级**：高 / 中 / 低
- **当前状态**：待筛选 / 待冻结 / 待写作 / 写作中 / 已发布 / 待改写

## 冻结前检查
在进入写作前，至少确认：
- 这个选题是否服务 Daniel实验室 的长期定位
- 有没有明确的核心判断
- 是否适合挂进现有专题
- 是否值得后续做平台改写
