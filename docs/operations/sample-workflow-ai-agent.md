## 2. 公众号改写草稿
### 标题候选
- AI Agent 不是先替代你，而是先重写你的工作流

### 开头
过去大家一提 AI，就喜欢问一句：它会不会替代人？
但我越来越觉得，这个问题问偏了。
真正先被改写的，往往不是岗位本身，而是岗位背后的那一连串流程。

### 结构
1. 先讲 AI Agent 为什么不是普通聊天机器人
2. 再讲办公室工作为什么最先受影响
3. 再讲 Daniel实验室 的判断：未来竞争不只是个人能力，而是谁先重组自己的工作流
4. 结尾引导回网站母稿与专题页

## 3. 小红书改写草稿
### 标题候选
- AI Agent 最先动的，不是你的岗位，是你的工作流
- 未来被改写最快的，可能是办公室这批人
- AI 不一定先替代你，但一定先改你的工作方式

### 正文草稿
AI Agent 最可怕的地方，不是它会聊天。
而是它开始接管“找资料、整理、判断、输出”这一整串流程。

对白领来说，这比“会不会被替代”更现实。
因为岗位名字可能没变，但做事方式已经开始变了。

Daniel实验室 的判断很简单：
下一轮差距，不是谁更会提问，
而是谁先把自己的工作流重组掉。
