# Daniel实验室 - 真实发布前人工审核口径

## 一、母稿一致性检查
- 平台草稿是否确实来自网站母稿
- 核心判断是否与母稿保持一致
- 是否出现平台稿和网站母稿互相打架的情况

## 二、内容质量检查
- 标题是否准确，不故意夸张到失真
- 开头是否足够抓人，但没有偏离原意
- 是否保留 Daniel实验室 的判断，而不是只剩信息搬运
- 是否有明显事实错误、时间错误、主体错误

## 三、平台适配检查
- 公众号：叙事是否完整，段落是否适合长文阅读
- 小红书：标题和正文是否足够卡片化、短句化
- 微博：是否足够短、够锐、够单一结论
- 技术博客：是否足够方法论化
- 抖音：是否适合口播，开头 3 秒是否成立

## 四、品牌口径检查
- 是否符合 Daniel实验室 当前定位
- 是否自然引导回网站母稿或专题，而不是把平台当主站
- 是否误把“项目”“作品集”等旧心智带回来了

## 五、发布安全检查
- 本阶段是否真的允许真实发布
- 是否涉及需要人工确认的外部账号动作
- 是否有敏感信息、未核实信息、版权风险

## 六、审核结论
审核后只能给三种结果：
- 通过：可进入排期
- 退回修改：指出具体修改点
- 暂缓：当前不建议进入真实发布
