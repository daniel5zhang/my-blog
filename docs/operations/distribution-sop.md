# Daniel实验室 - 网站母稿到外部分发改写 SOP

## 核心原则
网站是唯一母稿源头。

任何外部分发版本，都应当从网站母稿改写，而不是反过来让平台文案决定网站结构。

## 基本流程
1. 先完成网站文章母稿
2. 在网站内完成标题、摘要、专题归属、标签归属
3. 基于同一母稿改写不同平台版本
4. 进入人工审核
5. 审核通过后，再决定是否发布到外部平台

## 平台改写口径
### 1. 网站母稿
目标：
- 表达最完整
- 保留判断、证据、结构和上下文
- 作为后续一切版本的唯一源头

### 2. 公众号
改写重点：
- 更完整的叙事
- 更强的开头吸引力
- 更适合长文阅读节奏
- 保留结尾引导读者回站内订阅或查看专题

### 3. 小红书
改写重点：
- 标题更抓人
- 结构更短句、更卡片化
- 重点突出结论、情绪点、反差点
- 不直接照搬网站正文

### 4. 微博
改写重点：
- 提炼单一核心观点
- 用短句快速表达冲突或判断
- 可以作为文章观点切片，而不是全文摘要

### 5. 技术博客
改写重点：
- 更偏方法论与技术细节
- 弱化品牌导语，强化结构与可复用信息
- 适合发布到偏技术社区

### 6. 抖音
改写重点：
- 提炼成口播脚本
- 一开场先给冲突或结论
- 保留 3-5 个最关键点，不追求完整覆盖

## 禁止事项
- 禁止先写平台稿，再补网站母稿
- 禁止平台版本和网站母稿完全脱节
- 禁止未经确认直接自动发布到真实平台

## 推荐交付包
每篇内容建议形成一个发布包：
- 网站母稿
- 公众号版草稿
- 小红书版草稿
- 微博版草稿
- 技术博客版草稿
- 抖音口播脚本草稿
