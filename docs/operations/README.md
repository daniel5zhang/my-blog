# Daniel实验室 运营线文档索引

## 角色定位
本目录只承接**运营线资产**，不承接 OpenClaw 产品化手册正文，也不承接网站源码或正式文章资产。

### 本目录负责什么
- 运营规则、模板、台账、排期、审核、复盘
- 飞书主控台镜像、主控台同步规则、运营线双留存说明

### 本目录不负责什么
- 不负责 OpenClaw 产品化手册正文层
- 不负责 OpenClaw 产品化 SOP 主维护面
- 不负责 Daniel实验室 网站源码和正式文章
