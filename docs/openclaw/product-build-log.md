## 阶段 0：新站方案冻结
- 明确新站完全替代旧站
- 技术路线冻结为 Astro 5 + TypeScript + Astro Content Collections + Markdown/MDX
- 样式方案固定为 Tailwind CSS
- 评论方案固定为 Giscus
- 搜索方案第一阶段固定为 Pagefind
- 内容目录统一为 `articles / projects`
