# Daniel实验室 - 产品建设流程日志

> 用途：记录 Daniel实验室 从最初方案规划，到建站、定位收口、运营机制、样板母稿、试运行方案，再到主控台基础设施的持续建设过程。

## 阶段 0：新站方案冻结
- 明确新站完全替代旧站
- 技术路线冻结为 Astro 5 + TypeScript + Astro Content Collections + Markdown/MDX
- 样式方案固定为 Tailwind CSS
- 评论方案固定为 Giscus
- 搜索方案第一阶段固定为 Pagefind
- 内容目录统一为 `articles / projects`

## 阶段 1：基础页面与内容结构落地
- 首页、分类、标签、归档、订阅、搜索等基础页面逐步落地
- 共享配置收敛到 `src/lib/site.ts`
- 补齐本地 Docker 部署基础

## 阶段 2：旧站迁移规划与第一批内容迁移
- 完成旧站迁移规划、切换清单、URL 重定向规划、内容盘点
- 执行第一批内容迁移：`content/articles` + `content/science` → `src/content/articles/`
- 明确第一批不迁移 diary / easyclaw / skills

## 阶段 3：Daniel实验室 站点定位收口
- 站点名称改为 `Daniel实验室`
- 副标题定为 `AI、自动化与数字工作流观察`
- 一级结构收敛为：首页、文章、专题、标签、归档、关于、订阅、搜索
- 前台不再暴露项目栏目，`projects` 降级为兼容说明层

## 阶段 4：运营规则与 Agent 半自动 SOP
- 建立 Agent 职责边界
- 建立网站母稿 → 多平台改写 SOP
- 明确自动执行与人工确认边界
- 固定内容生产节奏与发布节奏
