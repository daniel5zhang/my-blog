# OpenClaw 产品化文档索引

## 角色定位
本目录只承接 **OpenClaw 产品化资产** 的 GitHub 备份层与规则层，不承接运营台账，也不承接网站源码与正式文章。

## 一、OpenClaw 产品化三层结构

### 1. Wiki 正文层
- 飞书 Wiki：`OpenClaw产品化手册`
- 承载正式手册正文、章节、长期知识、交付表达

### 2. Bitable 索引层
- 飞书多维表格：`OpenClaw产品迭代`
- 承载知识库链接、GitHub 文档链接、状态、阶段、下一步

### 3. GitHub 备份层
- 本目录 `docs/openclaw/`
- `docs/operations/bitable-mirror/`
- README、SOP、镜像、日志、`CHANGELOG.md`

## 二、本目录负责什么
- OpenClaw 产品化规则与 SOP
- 产品建设日志与阶段方法论
- 手册维护规则、知识库操作 SOP、角色模板、提示词库
- GitHub 侧的长期备份与审计留痕

## 三、本目录不负责什么
- 不负责运营线台账主维护
- 不负责站点源码、页面、配置、正式文章主维护
- 不把长正文手册直接塞进 GitHub README 或 Bitable

## 六、当前正式手册维护口径
- 一级主题保留在根级，作为稳定骨架
- 关键二级正文 move 到对应一级主题下
- 正文新增优先更新 Wiki 正文层
- 状态与链接变化优先更新 Bitable 索引层
- 最后统一回写 GitHub 备份层与 `CHANGELOG.md`

## 七、与其他资产层的边界
- 运营线文档请转到：`docs/operations/README.md`
