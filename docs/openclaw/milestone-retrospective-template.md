# OpenClaw产品化手册里程碑复盘模板

## 使用场景
用于 Daniel实验室 / OpenClaw 在完成一个明确阶段后，输出正式的里程碑复盘结果。

适用于：
- 新阶段结构完成
- 新规则 / SOP 冻结
- 知识库、索引层或 GitHub 结构明显升级
- 需要沉淀可复刻、可交付的阶段结论

## 执行步骤
1. 明确本次里程碑的名称与范围
2. 列出本阶段新增或升级的正式资产
3. 归纳本阶段的关键决策
4. 说明 Wiki / Bitable / GitHub 三层分别发生了什么变化
5. 记录遗留问题、失败卡点和未完成项
6. 提炼后续阶段的入口动作
7. 回写 GitHub 与必要索引层

## 必填项
- 里程碑名称
- 时间范围
- 目标与范围
- 已完成资产
- 关键决策
- 三层结构变化
- 风险与限制
- 未完成事项
- 下一阶段建议

## 输出格式
建议固定使用：

- 里程碑名称：
- 时间范围：
- 本阶段目标：
- 已完成内容：
- 关键决策：
- Wiki 正文层变化：
- Bitable 索引层变化：
- GitHub 备份层变化：
- 风险与限制：
- 未完成事项：
- 下一阶段建议：

## 最小留痕要求
- 必须更新 GitHub 正式文档与 `CHANGELOG.md`
- 若本阶段有新增正文，必须同步到 Wiki 正文层
- 若本阶段有可检索的正式资产，必须同步到 Bitable 索引层
- 不得只在聊天里完成复盘而不留正式记录

## 与已有 SOP 的关系

- 执行时必须服从：
  - `manual-maintenance-sop.md`
  - `asset-sync-sop.md`
  - `feishu-knowledgebase-sop.md`
